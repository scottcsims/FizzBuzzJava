# FizzBuzz Java

A classic [FizzBuzz](https://en.wikipedia.org/wiki/Fizz_buzz) implementation in Java — built as a demo project for exploring IDE setup, Maven builds, unit testing, and code coverage.

## Rules

For each number from 2 to 100,000:

| Condition              | Output       |
|------------------------|--------------|
| Multiple of 3 **and** 5 | `FizzBuzz` |
| Multiple of 3 only      | `Fizz`     |
| Multiple of 5 only      | `Buzz`     |
| Neither                  | The number |

## Prerequisites

- **Java 17** (e.g. [Amazon Corretto](https://aws.amazon.com/corretto/))
- **Maven 3.8+**

## Build & Run

```bash
# Compile the project
mvn clean compile

# Run the application
mvn exec:java -Dexec.mainClass="dev.ssims.fizzbuzz.Main"

# Or run the compiled class directly
java -cp target/classes dev.ssims.fizzbuzz.Main
```

## Testing

Tests are written with [JUnit 5](https://junit.org/junit5/) and cover the `multipleOf` helper method across multiple scenarios.

```bash
# Run all tests
mvn test
```

### Test Coverage

Code coverage is generated by [JaCoCo](https://www.jacoco.org/) automatically when tests run. After `mvn test`, open the report at:

```
target/site/jacoco/index.html
```
